CODE ROVER / SECTOR 07

탐사 로봇을 움직여라

명령을 연결하고 실행해 에너지 코어를 회수하세요.

탐사 구역 · 위에서 본 지도방향: 오른쪽
◆ 에너지 코어▧ 접근 불가▲ 로봇이 보는 방향

로봇은 자신이 바라보는 방향으로 전진합니다.
회전은 제자리에서 방향만 바꿉니다.

실행 순서
명령을 누르면 삭제됩니다.
코어까지의 길을 보고 명령을 추가하세요.
활동 안내 · 학습목표

학습목표: 이동과 회전 명령을 순서대로 구성하고 실행 결과를 바탕으로 알고리즘을 수정할 수 있다.

실행할 때마다 로봇은 출발점으로 돌아갑니다. 벽에 닿거나 명령이 끝나면 멈춥니다. 코어 위치에서 모든 명령을 마쳐야 성공합니다. 정답 명령은 공개되지 않으며, 여러 해결 방법이 가능합니다.

교과 확장 예시입니다. 교과서·성취기준 대조 전이며, 기록은 이 브라우저에만 저장됩니다.
